系统空间 · 安全维护

C 盘不只有“软件”和“大文件”

AppData 的小文件、商店应用、更新组件和系统保留空间，都可能占用很多。先测量，再使用 Windows 提供的维护功能。

点击分析会在“磁盘大文件”页面扫描系统盘。已有扫描结果会保留在该页面。

推荐：Windows 磁盘清理

查看更新清理、临时安装文件和旧系统。进入后选择“清理系统文件”，逐项检查。删除旧系统会失去回退能力。

存储设置

查看“系统和保留”、临时文件、应用和回收站。清理前留意“下载”是否被选中，那里可能是个人文件。

WinSxS 组件仓库

文件存在硬链接，目录求和并不等于真实独占空间。先用 DISM 官方分析查看是否建议清理（需要管理员权限）。

这些文件应保留

Installer 用于安装修复；DriverStore 是驱动仓库；pagefile.sys 是虚拟内存；hiberfil.sys 用于休眠和快速启动。不要直接删除，也不自动关闭相关功能。
